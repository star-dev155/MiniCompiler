# MiniCompiler

A lightweight compiler project

## Overview

MiniCompiler is a personal software development project focused on understanding how compilers interpret and process source code.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/star-dev155/MiniCompiler.git
```

### 2. Navigate to the project

```bash
cd MiniCompiler
```

### 3. Open the solution

Open `MiniCompiler.slnx` in a compatible version of Visual Studio.

### 4. Build and run

Use Visual Studio to restore dependencies, build the solution, and launch the appropriate startup project.
